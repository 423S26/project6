## SOAP
- __Subjective__ → Patient reported information such as symptoms and personal views or feelings
- __Objective__ → Measurable data such as vital signs, physical examination, lab data, etc...
- __Assessment__ → Documents findings about both subjective and objective data to arrive at diagnosis
- __Plan__ → Proposed treatments, additional testing, consultation with specialist, etc...
## The Application
This app makes taking HIPAA-compliant SOAP notes easy by allowing structured data entry and import/export functionality. There is no database connected to the app so all patient data is stored locally on the users computer.
