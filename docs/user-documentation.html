The word processor creates, edits, formats, stores and prints text based documents. It’s unique because it converts raw therapist notes into a comprehensive, orderly piece of documentation called SOAP notes of each patient.

SOAP is an acronym that stands for:

  • Subjective
  • Objective
  • Assessment
  • Plan

Once the file is converted, the user can save the file in their own computer. Our client wants it to make documentation streamlined and secure, the client also wants to share the documents with clients and other individuals related to the patient (e.g. the patient’s parents) since they like seeing the notes our client takes.

To access word processor, just click on the link below:

Word Processor

Directions

  1. Open the word processor using the link above titled Word Processor
  2. If you want to import a Word document: Click on the "Open" button on the utility bar at the top of the section
  3. If you want to make a new project: Start typing your treatment notes in the blank space
  4. Click the save button at the bottom of the section once you're finished
    1. IMPORTANT: Do not exit the application before you're done, it will not save! Please complete and save what you have before exiting or closing the window
  5. Repeat for each section until you have each section saved in your computer
