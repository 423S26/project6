Project setup

If you want to manually set up the project, you'll need to install:

  • React
  • Vercel to host the project publicly
  • Node.js: v18.x or higher recommended
  • Package Manager: npm or yarn.
  • Jest
  • React Testing Library
  • React Quill

The link to React Quill documenation is below

React Quill

The project source code can be obtained through GitHub at https://github.com/423S26/project6. Clone the repository, and now you’ll have it on your machine. To start the website on local host run the command "npm start"

This app is tested using Jest, React Testing Library and PlayWright. To run unit tests using Jest enter "npm test" on the command line. To execute E2E tests with PlayWright use "npx playwright test"

Common Commands

  • npm install - Install all dependencies.
  • npm start - Run the app in development mode at localhost:3000.
  • npm run build - Create a production-ready bundle in the /build folder.
  • npm test - Execute the Jest test suite.

React Components

  • Header → Header on top of page with link to documentation site on GitHub Pages
  • GeneralNotes → Container for React Quill for basic document editing
  • SoapBox → Container for React Quill to save formatting for SOAP

Vercel vs GitHub Pages

Vercel is the cloud platform this app is deployed to, and it auto updates the hosted website with each push to the project6 repository. GitHub Pages is the site where the documentation for the application is hosted.

Data flow of application

App.tsx is basically the index page of the app. It passes the title prop (Subjective, Objective, etc..) to the SoapBox component so that each element of SOAP is displayed correctly. The Header component is displayed at the top of the screen and contains the title of the app as well as a link to documentation. The GeneralNotes component contains the logic for the main editor.
